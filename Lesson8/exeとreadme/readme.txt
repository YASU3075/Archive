チキチキシューティング

※ゲーム内にも説明がありますがそれよりも細かいルールやこだわったポイントを書いてます

操作方法
・A,1キーで左移動　D,3キーで右移動
・スペースキーで弾を発射

ルール説明
・敵が打ってくる弾をぎりぎりまでひきつけて弾を当てることでその位置のスコアを獲得
・敵の弾に当たらないところに打ってしまうとそのレーンの0点のところで止まってしまい
　スコア獲得のチャンスを逃してしまう
・近すぎるところで当ててしまうとスコアがマイナスされてしまう

こだわったポイント
・弾のメモリ管理をプールアロケーターを使用することでメモリ効率を向上
・DrawManagerを作成し各Cellごとに情報を書き込んだりして変更のあるところだけ描画するよう効率化した
・Bullet同士の衝突判定処理を学習した並列処理を使用した
